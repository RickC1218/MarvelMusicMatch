# Capturas de la aplicación

Aquí van las capturas de la web **en funcionamiento** (no los mockups de Figma,
esos están en `screens/`).

El README espera exactamente estos dos archivos:

| Archivo | Contenido |
| --- | --- |
| `home.png` | Página de inicio (Home) |
| `personaje.png` | Detalle de un personaje con su playlist generada |

Recomendaciones: PNG, ~1440 px de ancho, ventana del navegador a tamaño normal
(sin la barra de desarrollo abierta).
